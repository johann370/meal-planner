# File map

Every file and folder in this repo, one line each on what it is and why it
exists. Nothing in here should stay a mystery box.

## Status definitions

- **known** — I've explained what it is and why it exists, in my own words.
- **parked** — honest one-liner for now; a real deep-dive is scheduled for
  later (usually the build-plan section that introduces it).
- **generated** — machine-made. Never hand-edit; regenerated by a tool.

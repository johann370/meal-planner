# What should the app do

`[x]` implemented · `[ ]` not yet (partial progress noted inline)

## Accounts & permissions

- [ ] Users should have their own accounts — **partial:** single shared password login, no per-user accounts
- [ ] Users shouldn't be able to edit anyone else's planner/recipes without permission
- [ ] Users should be able to give others permission to their meal planners
- [ ] Users should be able to view recipes that are in meal planners they have permission to (including public planners), even if the recipe is private

## Recipes

- [x] Users should be able to create their own recipes
- [ ] Users should be able to create recipe from a URL — **partial:** frontend calls it, but the backend route is commented out
- [x] Users should be able to edit their own recipes
- [x] Users should be able to delete their own recipes
- [x] Users should be able to view recipes in detail
- [ ] Users should be able to search and filter through recipes
- [ ] Users should be able to favorite recipes
- [ ] Users should be able to rate recipes
- [ ] Users should be able to see the average rating of public recipes

## Meal planners

- [ ] Users should be able to have multiple meal planners
- [ ] Users should be able to give their meal planners a title
- [ ] Users should be able to make their meal planners public so anyone can view them
- [ ] Users should be able to add multiple recipes to a meal planner for each day of the week — **partial:** one recipe per day only
- [x] Users should be able to remove recipes from the meal planner
- [x] Users should be able to clear their meal planners
- [ ] Users should be able to delete their meal planners
- [ ] Users should be able to share their planners with others (viewing/editing the same planner)

## Grocery list

- [x] Users should be able to view a grocery list for the recipes in their planner
- [ ] Users should be able to check off grocery list items while shopping

## Suggestions & personalization

- [ ] Users should fill out a questionnaire of their likes, dislikes, and favorite types of food when they create their account
- [ ] Users tastes, likes/dislikes, should be tracked
- [ ] Users should be able to get recipe suggestions
- [ ] Users should be able to describe the kind of recipe they are looking for and get a suggestion back
- [ ] Users should be able to get weekly meal plan suggestions
